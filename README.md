## What is it?

Quackle has a feature where it will output a report of its analysis of an entire Scrabble game. This web app takes that report and makes it easier to read and understand.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
